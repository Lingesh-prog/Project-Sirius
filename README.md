# Project Sirius 🚀

> An AI-powered personal assistant for everyday life.

Project Sirius is a long-term personal AI assistant project inspired by
the concept of JARVIS from Iron Man.

The goal is to build Sirius progressively through independent modules
that can eventually work together as one intelligent personal assistant.

## Current Module

### Sirius Focus

An AI-powered personal task and reminder assistant designed to help
users manage important tasks, deadlines and everyday responsibilities.
